# Vocabulary — People, Ages, Life Stages & Describing the World

> Build a rich vocabulary for describing people, life events, and the world around you.

---

## Part 1: Age Stages — Names for Every Phase of Life

| Age Range | Word | Notes |
|-----------|------|-------|
| 0–1 month | **Newborn** | Just born |
| 1 month – 1 year | **Infant / Baby** | Infant (formal), Baby (common) |
| 0–1 year | **Baby** | General use |
| 1–3 years | **Toddler** | Learning to walk, talk |
| 4–12 years | **Child** | School age |
| 9–12 years | **Preteen / Tween** | Between child and teen |
| 13–19 years | **Teenager / Teen / Adolescent** | Adolescent is formal |
| 18–25 years | **Young adult** | Early adulthood |
| 20s–30s | **Adult / Grown-up** | Fully grown |
| 30s–40s | **Middle-aged** (starts ~40) | Mid-life |
| 60+ years | **Senior citizen / Elder / Elderly** | Old age |
| 80+ years | **Octogenarian** | In their 80s |
| 100+ years | **Centenarian** | 100+ years old |

### In a Sentence
```
She just had a newborn baby girl.
The toddler was running around the park.
Teenagers often feel misunderstood.
He's in his mid-thirties now.
She is a senior citizen who loves gardening.
```

## Part 2: Describing People — Appearance

### Height
```
tall, short, medium height, average height
towering (very tall), petite (small and delicate, for women)
```

### Build / Body Type
```
slim / slender        → thin, but attractively so
lean                  → thin and fit
athletic / muscular   → strong body
stocky                → short and strong
chubby / plump        → slightly overweight (gentle word)
overweight / heavy    → more direct
```

### Face
```
round face / oval face / square jaw
fair skin / dark skin / wheatish complexion
wrinkled / smooth skin
dimples / freckles
```

### Hair
```
straight / curly / wavy / frizzy
shoulder-length / short / long / bald
dark brown / blonde / auburn (red-brown) / salt-and-pepper (grey + black)
```

### Eyes
```
almond-shaped / round / deep-set
bright eyes / sharp eyes / expressive eyes
```

## Part 3: Describing Personality

### Positive Traits
| Word | Meaning |
|------|---------|
| **confident** | sure of oneself |
| **ambitious** | wants to achieve great things |
| **diligent** | hardworking, careful |
| **reliable** | can be trusted |

| Word | Meaning |
|------|---------|

| **stubborn** | won't change their mind |

### Mixed Traits
| Word | Meaning |
|------|---------|

| **detail-oriented** | pays attention to small things |
| **laid-back** | relaxed, easygoing |

## Part 6: Numbers, Quantities & Frequency

### Frequency Words (Most → Least)
```
always → usually → often → sometimes → occasionally → rarely → seldom → never
100%  →  80%   →  60%  →    40%    →      20%      →   10%  →   5%   →   0%
```

### Quantity Words
```
Countable:           Uncountable:
many / a few         much / a little
several              a great deal of
a number of          a large amount of
countless            plenty of (both)
```

### Approximate Numbers
```
about / around / approximately   → "about 50 people"
roughly                          → "roughly 3 hours"
nearly / almost                  → "nearly 100"
over / more than                 → "over 500"
under / fewer than               → "under 20"
a couple of                      → about 2
a dozen                          → 12
a handful of                     → small number
```

## Part 7: Words That Change Everything — Degree Words

> These words make your language stronger, softer, or more precise.

### Intensifiers (Stronger)
```
very, extremely, incredibly, absolutely, totally, completely, deeply, highly, utterly
"She is extremely talented."
"I'm absolutely exhausted."
```

### Downtoners (Softer / Less)
```
quite, rather, fairly, somewhat, a bit, a little, slightly
"It's quite difficult."
"I'm a little tired."
"He's somewhat rude."
```

### So vs Such
```
so   + adjective/adverb    → "It's so beautiful."
such + (a/an) + noun       → "It's such a beautiful day."
                           → "She has such talent."
```

## Part 8: Describing Emotions Precisely

> Instead of always saying "happy", "sad", "angry" — use richer words.

### Better Than "Happy"
```
content → quietly satisfied
pleased → mildly happy
thrilled → very excited and happy
ecstatic → extremely happy
elated → joyfully happy
```

### Better Than "Sad"
```
disappointed → expected more
upset → troubled emotionally
heartbroken → very sad about a loss
gloomy → low, dark mood
devastated → completely broken emotionally
```

### Better Than "Angry"
```
annoyed → mildly irritated
frustrated → unable to achieve what you want
furious → very angry
outraged → shocked and angry at injustice
livid → extremely angry (informal)
```

### Better Than "Scared"
```
nervous → before an event
anxious → worried about future
terrified → very scared
petrified → frozen with fear
on edge → tense and alert
```

### Better Than "Surprised"
```
shocked → strong surprise (often bad)
stunned → speechless with surprise
astonished → amazed
bewildered → confused and surprised
```

## Part 9: Collocations — Words That Go Together

> Wrong: "make a bath" → Right: "take a bath"
> Collocations = words that naturally live together.

### Do / Make / Take / Have
```
DO:
do homework / do exercise / do a favor / do business / do research / do damage

MAKE:
make a mistake / make a decision / make progress / make money / make an effort / make a difference / make friends / make a call / make sense

TAKE:
take a break / take a photo / take a risk / take turns / take notes / take care of / take advantage of / take a shower / take a nap / take responsibility

HAVE:
have breakfast / have a meeting / have fun / have a conversation / have a problem / have a look / have a word with / have a cold
```

### Common Pairs (Adjective + Noun)
```
make a careful decision
give a detailed explanation
face a tough challenge
provide a clear answer
reach a final conclusion
take a deep breath
play a key role
pay close attention
```
