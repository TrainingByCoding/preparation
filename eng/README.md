## How to Make It Stick

1. **Read out loud** — hearing yourself say correct sentences builds muscle memory
2. **Cover answers first** — try every exercise before checking
3. **Write your own examples** — 5 sentences/day using today's topic
4. **Say it in real life** — next conversation, use one new structure on purpose
5. **Spot mistakes** — when you read/hear English, identify the tense/modal being used
