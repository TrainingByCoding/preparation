# Conditionals — "If" Sentences

> Conditionals describe situations and their results.
> Master formula: **IF + condition → result**

---

## The 5 Types At a Glance

| Type | Name | Reality | IF clause | Result clause |
|------|------|---------|-----------|---------------|
| **Zero** | Facts/Always true | Always true | Present Simple | Present Simple |
| **First** | Real/Likely | Very possible | Present Simple | will + base verb |
| **Second** | Unreal/Imaginary | Unlikely or impossible | Past Simple | would + base verb |
| **Third** | Past regret | Impossible (past is over) | Past Perfect | would have + V3 |
| **Mixed** | Past cause, present result | Impossible | Past Perfect | would + base verb |

---

## Zero Conditional — Universal Truths

> **"If X always happens, Y always happens."**
> Real, always true, scientific facts.

**Formula:** `If + Present Simple, Present Simple`

```
If you heat water to 100°C, it boils.
If it rains, the ground gets wet.
If you don't eat, you get hungry.
If I miss the bus, I take a taxi.
```

> You can replace "if" with "when" — same meaning here.
> `When you heat water, it boils.`

---

## First Conditional — Real Future Possibility

> **"If this happens (and it's likely), then this will happen."**
> Real situation. You're talking about something that CAN actually happen.

**Formula:** `If + Present Simple, will + base verb`

```
If it rains, I will stay home.
If you study hard, you will pass.
If she calls me, I will answer.
If we leave now, we will catch the train.
```

**Variations with modals:**
```
If you practice, you can improve.         ← can (ability)
If you're tired, you should sleep.        ← should (advice)
If he arrives early, we might start soon. ← might (possibility)
```

**Negative forms:**
```
If you don't hurry, you will miss the flight.
If he doesn't call, I won't wait.
```

---

## Second Conditional — Imaginary / Unlikely

> **"If this were true (but it isn't), this would happen."**
> Imaginary situations. You know it's not real.

**Formula:** `If + Past Simple, would + base verb`

```
If I had a million dollars, I would travel the world.
If I were you, I would apologize.
If she knew the answer, she would tell us.
If it didn't rain, we would have a picnic.
```

> **Special grammar note:** With the verb "be", use **were** for all subjects (formal/correct):
> ❌ If I was rich...  → ✅ If I **were** rich...
> (In casual speech, "was" is common, but "were" is grammatically correct)

**First vs Second — Key Difference:**
```
"If it rains tomorrow, I will stay home."   ← First  (real possibility — might actually rain)
"If it rained every day, I would move."     ← Second (imaginary — not the reality here)

"If I have time, I will help you."          ← First  (I might have time)
"If I had more time, I would learn piano."  ← Second (I don't have time — imaginary wish)
```

---

## Third Conditional — Past Regrets / "What If"

> **"If X had happened (but it didn't), Y would have happened."**
> Impossible to change — the past is done. Used for regrets, excuses, analyzing the past.

**Formula:** `If + Past Perfect (had + V3), would have + V3`

```
If I had studied harder, I would have passed.
If she had left earlier, she wouldn't have missed the bus.
If I had known, I would have told you.
If he hadn't helped me, I would have failed.
```

**Real-life feeling:**
```
"If I had saved money, I would have bought a house." 
→ (I didn't save → I didn't buy a house. I regret it.)

"If she had come to the party, she would have met him."
→ (She didn't come → they didn't meet. Too bad!)
```

**Negative forms:**
```
If I hadn't missed the meeting, I would have gotten the project.
If you hadn't told me, I wouldn't have known.
```

---

## Mixed Conditional — Past Cause, Present Result

> **"If X had happened in the past, I would be in a different situation now."**
> Mixing past condition with present result.

**Formula:** `If + Past Perfect, would + base verb (present)`

```
If I had studied medicine, I would be a doctor now.
If she had accepted the job, she would be living in New York now.
If he hadn't lost his passport, he would be in Paris now.
```

**Compare with Third:**
```
Third:  "If I had studied, I would have passed."   ← past cause → past result
Mixed:  "If I had studied, I would be an engineer." ← past cause → PRESENT result
```

---

## UNLESS — The "Except If" Word

> `Unless = if... not`

```
Unless you hurry, you'll be late.        = If you don't hurry, you'll be late.
Unless it rains, we'll go outside.       = If it doesn't rain, we'll go outside.
I won't help you unless you ask nicely.  = I won't help you if you don't ask nicely.
```

---

## Common Conditional Expressions

| Expression | Meaning | Example |
|------------|---------|---------|
| `as long as` | only if / on condition that | I'll go **as long as** you come too. |
| `provided that` | only if | You can borrow it **provided that** you return it. |
| `even if` | regardless of the condition | I'll help **even if** I'm tired. |
| `in case` | precaution | Take an umbrella **in case** it rains. |
| `supposing` | imagining | **Supposing** you won the lottery, what would you do? |

---

## The Common Mistake Zone ⚠️

```
❌ If I will go, I will call you.
✅ If I go, I will call you.           ← No "will" in the IF clause

❌ If I would know, I would tell you.
✅ If I knew, I would tell you.        ← No "would" in the IF clause (2nd conditional)

❌ If she would have studied, she would have passed.
✅ If she had studied, she would have passed.   ← 3rd conditional: had + V3

❌ Unless you don't eat, you'll be hungry.
✅ Unless you eat, you'll be hungry.   ← "unless" already means "if not"
```

## Quick-Fire Quiz 🔥

Complete the sentences:

1. If you touch fire, you ___ (get) burned. *(zero)*
2. If I find your keys, I ___ (call) you. *(first)*
3. If I ___ (be) the president, I would change everything. *(second)*
4. If she ___ (study) harder, she would have graduated. *(third)*
5. If I had taken that job, I ___ (live) in London now. *(mixed)*
6. ___ you hurry, you will be late. *(unless)*

**Answers:**
1. get
2. will call
3. were
4. had studied
5. would be living
6. Unless

## Story-Based Practice

> Read this story and identify the conditional types:

*"Everyday Tom wakes up. If he wakes up late, he misses his bus." (___)*

*"Today Tom thinks: If I wake up early tomorrow, I will catch the 7am bus." (___)*

*"His friend says: If I were Tom, I would set two alarms." (___)*

*"Tom remembers: If I had slept earlier last night, I wouldn't have been tired." (___)*

*"He wishes: If I had bought a car last year, I would be driving to work now." (___)*

**Answers:** Zero, First, Second, Third, Mixed

## Summary Snapshot

```
ZERO     → Always/Facts      → If + V1, V1
FIRST    → Real possibility   → If + V1, will + V1
SECOND   → Imaginary now      → If + V2, would + V1
THIRD    → Past regret        → If + had + V3, would have + V3
MIXED    → Past → Now         → If + had + V3, would + V1
```
